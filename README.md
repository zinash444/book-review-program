# Book Review Program

A simple Python program where users can write and view reviews of books.

## What it does

- Shows a list of available books
- Asks the user for their username
- Lets the user choose a book
- Lets the user write a review
- Stores each review in a dictionary
- Stores all reviews in a list
- Displays all reviews when the program ends
